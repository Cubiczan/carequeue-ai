## Scene 4: How It Works — Architecture (2:05–2:35)

**[Visual: Animated architecture diagram or D2 diagram]**

**Narrator:**

> "Under the hood, HealthGuard AI runs on a modern stack — Next.js on the frontend with React, Recharts for data visualization, and Prisma for patient data management. The intelligence layer is Google Gemini, accessed through a secure API gateway. Vitals flow in through our REST API, where an auto-alert engine checks every reading against clinical thresholds — heart rate, blood pressure, oxygen saturation, temperature. If anything's abnormal, an alert is generated in real time. The entire system is designed for HIPAA-conscious deployment with minimal data exposure."

- **On-camera segments:** Soft lighting, solid color background (teal or dark grey)
- **Text overlays:** Clean sans-serif font, fade-in animations
- **File:** Export as MP4, 1080p, under 500MB for Devpost upload
