# Audit Trail

Auto-generated by Claude / the multi-agent system after each closed-loop run.

Naming: `YYYY-MM-DD audit-note - <event>.md`

Each note contains:
- Inputs read (file paths + hashes)
- Skills/agents invoked
- Decisions surfaced (with Notion row IDs)
- Outputs written (file paths)
- Open follow-ups

Do **not** edit these files manually — they are the immutable audit record. Corrections go in a new note.
