# Closed Loop Finance Skill Pack

Drop the four base skills here. Each subdirectory is a self-contained skill.

| Skill | Purpose |
|---|---|
| `closed-loop-brain` | Orchestrates the loop: read → reason → decide → remember |
| `closed-loop-memory` | Reads/writes Notion Decision Log; checks prior context before recommending |
| `closed-loop-audit` | Generates the immutable audit note for every run |
| `closed-loop-board-prep` | Builds the 3-message management/board summary |

To install: copy the unzipped skill-pack contents into this folder and reload Claude Cowork's skill manager.
