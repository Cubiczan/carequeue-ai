# Board Meetings

One subfolder per meeting: `YYYY-MM-DD Board Meeting/`.

Each subfolder contains:
- `pre-read.pdf`
- `deck.pptx` (or `.pdf`)
- `minutes.md`
- `action-items.md`
- `resolutions.pdf`

Material decisions surfaced in board meetings should be logged to the Notion Decision Log with `Category = Board`.
